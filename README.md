# EmoAlignBench Reproducibility Artifact

This repository contains the code, cached-score reproduction entry point, configuration files, paper figures, CSV/JSON tables, and validation utilities for **“EmoAlignBench: Open Multimodal Mining of Acoustic Friction in High-Stakes Financial Dialogues.”**

## Current source-of-truth policy

The final paper uses the manifest files as the only source of truth for supplemental diagnostics:

- `validation_report.json` -> `table_s1_validation_gates.csv` and `table_s1_validation_gates.json`
- `call_grouped_splits.json` -> `table_s2_call_grouped_splits.csv` and `table_s2_call_grouped_splits.json`

## What this package reproduces

The public release contains **142,751 timestamped utterance rows** from public earnings calls. The paper evaluates **812 signal-valid Analyst->Executive adjacency pairs** drawn from **95.07 hours** of Q&A-source audio. The cached analysis file `results/stress_pairs_with_acoustics.csv` contains 1,852 turn rows / 926 stress-triggered candidate pairs before signal-level pair QC.

Core fields:

- `text_valence`: transcript-side score, denoted v_text in the paper.
- `voice_valence`: released voice/acoustic score, denoted v_voice in the paper.
- `emotion_incongruence`: abs(v_text - v_voice), the acoustic-friction score.
- `f0_std_ratio`, `hnr_proxy_ratio`, `voice_arousal_ratio`: Executive/Analyst interactional ratios.
- `uid`: call identifier for call-clustered bootstrap, within-call permutation, and leakage-safe train/validation/test splits.

## Repository structure

```text
.
├── 00_preprocess_rawdata_to_transcripts.py   # optional ASR preprocessing for raw audio
├── 01_build_adjacency_pairs.py               # Q&A filtering and Analyst->Executive pair construction
├── 02_extract_acoustic_features.py           # audio slicing and acoustic feature extraction
├── 03_generate_paper_figures_tables.py       # Fig0-Fig3, main CSV tables, statistics JSON/CSV
├── 04_validate_release.py                    # validation report, call-grouped splits, S1/S2 CSV+JSON tables
├── run_reproduce_paper.py                    # one-command cached-score reproduction
├── configs/
│   ├── emobench_config.json                  # paper-matched dataset/statistical/artifact policy
│   └── asr_config.example.json               # private ASR endpoint template; no secrets included
├── prompts/text_valence_prompt.md            # deterministic text-score prompt template
├── data/linkto.txt                           # DOI and Hugging Face data pointer
└── results/                                  # cached scores and generated review artifacts when present
```

The public dataset is available via DOI `https://doi.org/10.57967/hf/7902` and Hugging Face dataset `soundai2016/EmoAlignBench`.

## Installation

Python 3.10+ is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`ffmpeg` is needed only for optional raw-audio conversion in Step 00.

## One-command reproduction from cached scores

Place the released `results/` directory under the repository root, then run:

```bash
python run_reproduce_paper.py
```

This regenerates or verifies:

```text
Fig0_Framework.{png,pdf}
Fig1_Landscape.{png,pdf}
Fig2_Raincloud.{png,pdf}
Fig3_Dynamics.{png,pdf}
table_baseline_stats.csv
table_ratio_stats.csv
table_robustness.csv
statistics_tables.json

paper_metrics.csv
validation_report.json
call_grouped_splits.json
table_s1_validation_gates.csv
table_s1_validation_gates.json
table_s2_call_grouped_splits.csv
table_s2_call_grouped_splits.json

```

By default, the figure script uses cached `statistics_tables.json` so the released numbers match the paper and avoid small numerical drift across library versions. To rerun Wilcoxon/FDR/bootstrap/permutation calculations from the cached turn table, use:

```bash
python run_reproduce_paper.py --recompute-stats
```

## Upstream reproduction steps

Cached-score reproduction is sufficient for paper review. To rebuild upstream artifacts from raw modality files, place the dataset contents under `data/` and run:

```bash
python 01_build_adjacency_pairs.py --data_dir data --results_dir results
python 02_extract_acoustic_features.py --data_dir data --results_dir results --scale_text_to_unit
python 03_generate_paper_figures_tables.py --recompute-stats
python 04_validate_release.py
```

Optional ASR preprocessing is separated because it depends on a private or institution-provided streaming ASR endpoint:

```bash
cp configs/asr_config.example.json configs/asr_config.private.json
python 00_preprocess_rawdata_to_transcripts.py --config configs/asr_config.private.json
```

Do not commit private tokens or ASR endpoint credentials.

## Scope and safety note

The scores are intended for research on multimodal financial dialogue and human-in-the-loop review. They should not be interpreted as deception detection, clinical assessment, or automated trading advice.
